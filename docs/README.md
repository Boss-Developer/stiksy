# Stiksy site (GitHub Pages)

Static pages served from this `docs/` folder. No build step.

| File | What it is |
|---|---|
| `index.html` | One-page home for the app |
| `privacy.html` | Privacy policy (the URL Play Console asks for) |
| `icon.png` | 512px app icon |

## Turn it on

GitHub repo **Settings > Pages**: Source **Deploy from a branch**, branch `main`, folder `/docs`, Save.
It only publishes what is on `main`, so merge or push this folder there first.

Live pages (repo `Boss-Developer/stiksy`):

- `https://boss-developer.github.io/stiksy/`
- `https://boss-developer.github.io/stiksy/privacy.html`

## Use the privacy URL

- **Play Console:** App content > Privacy policy > paste the `privacy.html` URL.
- **In the app:** Stiksy Admin > Settings > App texts > *Privacy URL*, then Publish.

## Contact email

`sfdevelopers.apps@gmail.com` appears in `privacy.html` and `index.html`.
